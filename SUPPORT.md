# Support

The documentation and live demo cover installation, Next.js usage, metadata
types, customization, and EXIF extraction.

- Use a bug report for reproducible defects.
- Use a feature request for proposed API or interface changes.
- Use a question issue for integration help that is not answered by the docs.
- Use private vulnerability reporting for security concerns.

Please never attach private client photographs or unredacted EXIF metadata to a
public issue.

Support is community-provided on a best-effort basis. There is no guaranteed
response time.
